# Campus Motion — Tombola

Version statique compatible avec GitHub Pages.

## Publication
1. Créer un dépôt consacré à la tombola sur le compte GitHub souhaité.
2. Déposer tous les fichiers de ce dossier à sa racine.
3. Dans Settings > Pages, choisir Deploy from a branch, puis main et / (root).
4. L’adresse prendra la forme https://COMPTE.github.io/DEPOT/.

## Données
Cette archive ne contient aucun participant ni nombre de tickets. Le CSV fourni contient seulement les en-têtes. Le site public ne charge une liste qu’après import manuel avec Gérer les données. L’import reste en mémoire dans le navigateur et disparaît au rechargement. Ne pas commiter un export réel du Sheet si ces données doivent rester privées.

## Connexion Google
La synchronisation privée n’est pas configurée. Elle nécessite une intégration authentifiée séparée ; GitHub Pages seul ne fournit pas cette connexion. Ne jamais ajouter de clé privée ou de mot de passe dans le dépôt ou dans JavaScript.
